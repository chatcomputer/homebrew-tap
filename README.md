# Homebrew tap for Chat Computer

```sh
brew install --cask chatcomputer/tap/chatcomputer
```

Installs [Chat Computer](https://github.com/chatcomputer/chatcomputer) into Applications and the `chatcomputer`
command line tool on your PATH. Requires macOS 27 on Apple silicon.

`brew upgrade --cask chatcomputer` updates it; the agent inside the virtual Mac updates itself when the app next
starts. `brew uninstall --zap --cask chatcomputer` also deletes the virtual Mac and its snapshots.
